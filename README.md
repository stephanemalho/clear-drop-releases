# Clear Drop — releases

Signed installers for [Clear Drop](https://cleardrop.app), for macOS and Windows.

**Download Clear Drop from [cleardrop.app/download](https://cleardrop.app/download).**
This repository only hosts the packages the app downloads when it updates itself.
It contains no source code.

Every package is signed. Clear Drop refuses to install an update that is not
signed with its own key.

Support: [cleardrop.app/support](https://cleardrop.app/support)
